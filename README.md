## 👨‍💻 Sobre mim

Sou **Kauã Daudt Gomes**, estudante de **Análise e Desenvolvimento de Sistemas na FIAP** e desenvolvedor backend em formação.

Tenho foco em **C#**, **.NET**, **APIs REST**, **SQL**, **MySQL**, **Docker** e boas práticas de arquitetura. Busco evoluir constantemente através de projetos acadêmicos, pessoais e desafios práticos.

Atualmente estou estudando e desenvolvendo projetos com:

- APIs REST com C# e .NET
- Autenticação e autorização com JWT
- Banco de dados SQL e MySQL
- Docker para padronização de ambientes
- Swagger e Scalar para documentação e testes de APIs
- Arquitetura em camadas
- Git e GitHub para versionamento
